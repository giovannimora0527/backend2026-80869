Guia de estudio 3 - Despacho y dispensacion (Fase 5)

Esta guia cubre la Fase 5 del sistema: el modulo de despacho, que gestiona la entrega real de los medicamentos formulados y es el unico punto donde se descuenta el inventario.

1. Vision general de la Fase 5

El objetivo es separar dos momentos que antes se confundian:

  • Formular (Fase 3): el veterinario prescribe medicamentos. NO afecta el inventario.
  • Dispensar (Fase 5): el personal de despacho entrega los medicamentos. Solo aqui se descuenta el inventario.

Esta separacion garantiza que el inventario solo se afecte cuando existe una entrega efectivamente realizada. El modulo lo opera el perfil DESPACHO_MEDICO.

2. El perfil DESPACHO_MEDICO

Rol con acceso restringido. Solo puede consultar el inventario (sin editar) y operar el modulo de despacho. No accede a citas, atencion, historias, creacion de formulas, facturacion, tarifas, reportes ni administracion.

Idea clave: la restriccion se valida en el backend (filtro de seguridad), no solo ocultando menus. Aunque se manipule la interfaz, el servidor rechaza las peticiones no autorizadas.

3. Modelo de datos

  • despacho: cabecera de la dispensacion (estado, fecha, responsable, observacion).
  • despacho_detalle: por medicamento, la cantidad solicitada, la entregada y el lote.
  • log_despacho: historial de cambios de estado, para trazabilidad.

Se relacionan con la formula, los lotes y los movimientos de inventario existentes.

4. La politica FEFO (First Expired, First Out)

Al confirmar un despacho, el sistema descuenta de los lotes empezando por el que vence primero (sin tocar los vencidos). "Primero el que expira antes." Evita que queden lotes viejos sin usar y es la forma correcta de manejar medicamentos.

5. El proceso paso a paso

  • Se consultan las formulas pendientes de dispensacion.
  • Al seleccionar una, se ven sus medicamentos con la cantidad prescrita y la existencia disponible (solo lotes vigentes).
  • Se registra cuanto se entrega de cada medicamento.
  • Al confirmar, de forma transaccional, el sistema descuenta los lotes (FEFO), genera un movimiento de salida por lote, guarda el detalle, actualiza el estado, registra el log y genera un comprobante PDF.

Transaccional significa que, si algo falla, no se aplica ningun descuento: o se hace todo o nada. El inventario nunca queda a medias.

6. Estados del despacho

  • PENDIENTE: la formula fue generada pero aun no se procesa.
  • EN_PREPARACION: se estan verificando medicamentos y cantidades.
  • DESPACHO_PARCIAL: se entrego solo una parte de lo formulado.
  • DESPACHADO: se entrego todo lo formulado.
  • PENDIENTE_DISPONIBILIDAD: faltan existencias para entregar.
  • CANCELADO: se cancelo mediante un procedimiento autorizado.

7. Reglas de negocio clave

  • Solo DESPACHO_MEDICO (y el administrador) operan el modulo.
  • El despacho no modifica las dosis ni cantidades prescritas por el medico.
  • El inventario se descuenta solo al confirmar la dispensacion.
  • No se dispensan medicamentos vencidos.
  • No se entrega mas de lo disponible; si no alcanza, se permite entrega parcial.
  • Cada salida queda ligada a un despacho y a una formula.
  • No se descuenta dos veces por una misma dispensacion.
  • Toda operacion registra usuario, fecha y hora.
  • Las dispensaciones confirmadas no se eliminan; se conserva el historial.

8. Como usar el modulo

Pestana Pendientes

  • Lista las formulas pendientes con propietario, mascota, medico y numero de medicamentos.
  • Boton "Preparar": abre el detalle con cada medicamento, su cantidad prescrita y la disponible. Se indica cuanto entregar y se confirma. Si se entrega menos de lo prescrito, el despacho queda parcial.

Pestana Historial

  • Lista los despachos realizados con fecha, estado y responsable.
  • Boton PDF: descarga el comprobante de despacho.

9. Flujo de prueba sugerido para la sustentacion

  • Mostrar en Inventario la existencia de un medicamento con lotes de distinta fecha de vencimiento.
  • Entrar con DESPACHO_MEDICO y mostrar que solo ve Inventario (consulta) y Despacho.
  • En Despacho, seleccionar una formula y confirmar la entrega.
  • Volver a Inventario y mostrar que la existencia bajo, tomando del lote que vence antes (FEFO).
  • Mostrar el movimiento de salida ligado a la formula.
  • Descargar el comprobante PDF.
  • Mostrar un caso de entrega parcial y explicar el estado.
  • Intentar acceder a un modulo no permitido con este rol y mostrar el rechazo del servidor.

10. Glosario

  • Dispensacion: entrega fisica de los medicamentos formulados.
  • Despacho: registro de una dispensacion, con su estado y detalle.
  • Lote: cantidad de un medicamento con un mismo precio y fecha de vencimiento.
  • FEFO: politica que descuenta primero del lote que vence antes.
  • Movimiento de salida: registro de la disminucion de inventario por una entrega.
  • Transaccional: operacion que se aplica completa o no se aplica.
  • DESPACHO_MEDICO: perfil que opera el modulo con acceso restringido.
